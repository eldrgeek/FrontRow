# Video Reviewer — Build & Run Notes

## Workarounds & API Quirks

### Gemini 2.5 Pro — 429 Credits Depleted (blocking)
The GEMINI_API_KEY in `~/Projects/CIE/secrets.yaml` returns 429 "prepayment credits
depleted." The runner now fails loudly per spec (no fallback to Claude-only mode).
To unblock:
- Visit https://ai.studio/projects → add billing / replenish credits
- Or replace GEMINI_API_KEY in secrets.yaml with a funded key

The v1 and v2 REVIEW.md files in output/ were generated by a prior dispatch that
used graceful degradation (Claude-only). These are valid single-reviewer results
but lack ensemble disagreement data and native video understanding from Gemini.

### Claude Model ID
`claude-sonnet-4-6` — no date suffix needed. Date-suffixed variants return 404.

### OpenAI Whisper
Works cleanly. 25MB file-size limit was not hit for either demo video (~1.6–3.3MB).
`verbose_json` with `timestamp_granularities: ["segment"]` gives time-aligned
transcript segments that map well to the timecode-based issue table.

### ffmpeg Keyframe Extraction
`fps=1/1.5,scale=960:540` at quality 5 produces ~20–40 frames per minute of video.
The runner caps at 40 frames sent to Claude to stay within vision token limits.
No issues encountered.

### Gemini Files API
Upload → poll for ACTIVE state → review → delete worked in testing (before credits
ran out). The processing wait loop uses 5-second intervals. No quirks observed
beyond the billing issue.
